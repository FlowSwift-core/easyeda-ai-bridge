Agent 配对页面

配对码
------
等待配对码...
连接步骤
1
在 Agent 端调用 /pairing/verify API，提交配对码进行验证
2
验证成功后获取 sessionId，后续请求需携带 X-Session-Id 请求头
3
调用 /execute 接口执行代码，结果会实时返回
API 示例
POST /pairing/verify
Body: { "code": "------" }
POST /execute
Header: X-Session-Id: <sessionId>
Body: { "code": "eda.sys_Storage.getExtensionUserConfig('test')" }
// 读取扩展配置
POST /execute
Header: X-Session-Id: <sessionId>
Body: { "code": "eda.sch_PrimitiveComponent.getAllPrimitiveId()" }
// 获取原理图中所有元件ID
POST /execute
Header: X-Session-Id: <sessionId>
Body: { "code": "eda.sch_PrimitiveComponent.get(['e1']).then(r=>r[0]?.designator)" }
// 获取指定元件信息
POST /execute
Header: X-Session-Id: <sessionId>
Body: { "code": "eda.dmt_Project.getCurrentProjectInfo().then(p=>p?.friendlyName)" }
// 获取当前工程名称
